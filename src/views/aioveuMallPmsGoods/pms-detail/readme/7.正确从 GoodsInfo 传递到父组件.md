我发现了问题！在父组件中，**你缺少了对 `v-model`的支持**。当你使用 `v-model`时，实际上需要的是 `:modelValue`和 `@update:modelValue`的组合，但你的父组件只是使用了 `v-model`而没有处理数据更新。

## 🔍 问题分析

```
<!-- 父组件中使用 v-model -->
<GoodsInfo
  v-if="activeStep === 1"
  v-model="goodsInfo"  <!-- 这里只是语法糖 -->
  @prev="handlePrevStep"
  @next="handleNextStep"
/>
```

`v-model`是语法糖，相当于：

```
<GoodsInfo
  v-if="activeStep === 1"
  :modelValue="goodsInfo"
  @update:modelValue="(value) => goodsInfo = value"  <!-- 你缺少这个！ -->
  @prev="handlePrevStep"
  @next="handleNextStep"
/>
```

## ✅ 修复方案

### 1. 修改父组件的监听方式

在父组件中，为每个子组件添加显式的 `@update:modelValue`处理：

```
<!-- 父组件 GoodsDetail.vue -->
<template>
  <!-- 步骤1：商品分类选择组件 -->
  <GoodsCategory
    v-if="activeStep === 0"
    v-model="goodsInfo"
    @prev="handlePrevStep"
    @next="handleNextStep"
    @edit-goods="handleEditGoods"
  />

  <!-- 步骤2：商品信息填写组件 -->
  <GoodsInfo
    v-if="activeStep === 1"
    v-model="goodsInfo"
    @prev="handlePrevStep"
    @next="handleNextStep"
    @update:modelValue="handleUpdateModelValue"  <!-- ✅ 添加这个 -->
  />

  <!-- 步骤3：商品属性设置组件 -->
  <GoodsAttribute
    v-if="activeStep === 2"
    v-model="goodsInfo"
    @prev="handlePrevStep"
    @next="handleNextStep"
    @update:modelValue="handleUpdateModelValue"  <!-- ✅ 添加这个 -->
  />

  <!-- 步骤4：商品库存设置组件 -->
  <GoodsStock
    v-if="activeStep === 3"
    v-model="goodsInfo"
    @prev="handlePrevStep"
    @next="handleNextStep"
    @submit-success="handleSubmitSuccess"
    @update:modelValue="handleUpdateModelValue"  <!-- ✅ 添加这个 -->
  />
</template>
```

### 2. 在父组件中添加处理函数

```
// 父组件 GoodsDetail.vue
/**
 * 处理子组件传递的数据更新
 */
const handleUpdateModelValue = (value: PmsSpuPageVO) => {
  console.log("📥 父组件收到 update:modelValue 事件:", {
    时间: new Date().toLocaleTimeString(),
    当前步骤: activeStep.value,
    name: value.name,
    price: value.price,
    originPrice: value.originPrice,
    categoryId: value.categoryId
  });
  
  // 更新父组件的 goodsInfo
  goodsInfo.value = {
    ...goodsInfo.value,  // 保留原有数据
    ...value,  // 合并新数据
  };
  
  console.log("✅ 父组件 goodsInfo 更新后:", {
    name: goodsInfo.value.name,
    price: goodsInfo.value.price
  });
};
```

### 3. 或者在父组件中使用显式绑定

如果你不放心 `v-model`，可以改为显式绑定：

```
<!-- 父组件 GoodsDetail.vue -->
<template>
  <!-- 步骤2：商品信息填写组件（显式绑定） -->
  <GoodsInfo
    v-if="activeStep === 1"
    :modelValue="goodsInfo"
    @update:modelValue="handleGoodsInfoUpdate"
    @prev="handlePrevStep"
    @next="handleNextStep"
  />
<
/template>
```

```
// 专门处理 GoodsInfo 的数据更新
const handleGoodsInfoUpdate = (value: PmsSpuPageVO) => {
  console.log("📥 GoodsInfo 组件更新数据:", {
    name: value.name,
    price: value.price,
    originPrice: value.originPrice
  });
  
  // 直接赋值
  goodsInfo.value = value;
  console.log("✅ 父组件 goodsInfo 已更新");
};
```

### 5. 在 GoodsInfo 组件中确认 emit 被调用

在 GoodsInfo 的 `handleNext`中添加确认：

```
// GoodsInfo.vue
const handleNext = async (): Promise<void> => {
  try {
    if (!dataFormRef.value) {
      console.error("表单引用未初始化");
      return;
    }

    // 表单验证
    const isValid = await dataFormRef.value.validate();
    console.log("✅ GoodsInfo 表单验证结果:", isValid);

    if (isValid) {
      // 额外的业务验证
      if (goodsInfo.value.price && goodsInfo.value.originPrice &&
        Number(goodsInfo.value.price) > Number(goodsInfo.value.originPrice)) {
        ElMessage.warning("促销价不能高于零售价");
        return;
      }

      console.log("✅ GoodsInfo 表单验证通过");
      
      // ✅ 关键：确保数据是完整的
      const dataToSend: PmsSpuPageVO = {
        ...goodsInfo.value,
        // 确保关键字段
        name: goodsInfo.value.name || "",
        price: goodsInfo.value.price !== undefined ? Number(goodsInfo.value.price) : undefined,
        originPrice: goodsInfo.value.originPrice !== undefined ? Number(goodsInfo.value.originPrice) : undefined,
        brandId: goodsInfo.value.brandId,
        picUrl: goodsInfo.value.picUrl || "",
        detail: goodsInfo.value.detail || "",
        // 确保数组字段
        album: goodsInfo.value.album || [],
        attrList: goodsInfo.value.attrList || [],
        specList: goodsInfo.value.specList || [],
        skuList: goodsInfo.value.skuList || []
      };
      
      console.log("📤 GoodsInfo 发送给父组件的数据:", {
        name: dataToSend.name,
        price: dataToSend.price,
        originPrice: dataToSend.originPrice,
        categoryId: dataToSend.categoryId
      });

      // ✅ 触发更新事件
      console.log("📤 正在调用 emit('update:modelValue', dataToSend)...");
      emit("update:modelValue", dataToSend);
      
      // ✅ 等待数据保存
      await new Promise(resolve => setTimeout(resolve, 200));
      console.log("✅ emit 调用完成");
      
      // ✅ 触发下一步事件
      console.log("➡️ 触发 emit('next')");
      emit("next");
    } else {
      console.log("❌ GoodsInfo 表单验证失败");
      ElMessage.warning("请填写完整的商品信息");
    }
  } catch (error) {
    console.error("表单验证出错:", error);
  }
};
```

## 关键检查点

- [ ] 父组件是否添加了 `@update:modelValue`监听
- [ ] `handleUpdateModelValue`是否被调用
- [ ] 父组件的 `goodsInfo`是否更新
- [ ] GoodsInfo 的 `emit`是否被调用
- [ ] 数据是否从子组件传递到父组件

这样修改后，数据应该能正确从 GoodsInfo 传递到父组件，再从父组件传递到 GoodsStock。
