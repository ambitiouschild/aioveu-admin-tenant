**问题找到了！** 你发现了关键问题。在步骤变化监听器中，你调用了 `router.replace()`来更新URL，这导致了页面重新加载，从而触发了路由监听器，清空了数据。

## 🔍 问题分析

你的代码中存在**循环触发**：

1. **步骤变化** → 触发 `watch(activeStep)`
2. **watch(activeStep) 中调用** `router.replace({ query: { step: newStep } })`
3. **URL变化** → 触发 `watch(() => route.query)`
4. **可能会触发其他副作用** → 数据丢失

## ✅ 修复方案

### 方案1：移除 router.replace（推荐）

如果你不需要在URL中保存步骤状态，直接移除这部分的代码：

```
// 监听步骤变化
watch(activeStep, (newStep, oldStep) => {
  console.log(`🔄 步骤变化: ${oldStep} -> ${newStep}`);
  console.log("🔍 切换时数据状态:", {
    名称: goodsInfo.value.name,
    价格: goodsInfo.value.price
  });

  // 删除以下代码，避免URL变化导致页面重载
  // const currentQuery = { ...route.query };
  // if (newStep === 0) {
  //   delete currentQuery.step;
  // } else {
  //   currentQuery.step = newStep.toString();
  // }
  // router.replace({
  //   query: currentQuery
  // }).catch(() => {});

  // 可以在这里添加步骤切换时的额外逻辑
  // 例如：保存当前步骤数据、验证当前步骤等
}, { immediate: true });
```

### 方案2：只在特定条件下更新URL

如果你需要在URL中保存步骤状态，但避免循环触发，可以添加条件判断：

```
// 监听步骤变化
watch(activeStep, (newStep, oldStep) => {
  console.log(`🔄 步骤变化: ${oldStep} -> ${newStep}`);
  console.log("🔍 切换时数据状态:", {
    名称: goodsInfo.value.name,
    价格: goodsInfo.value.price
  });

  // ✅ 添加条件：只有步骤真的变化时才更新URL
  if (newStep !== oldStep) {
    // ✅ 检查当前URL中的step参数
    const currentStepInUrl = parseInt(route.query.step as string) || 0;
    
    // ✅ 只有在URL中的step与当前step不同时才更新
    if (currentStepInUrl !== newStep) {
      const currentQuery = { ...route.query };
      if (newStep === 0) {
        delete currentQuery.step;
      } else {
        currentQuery.step = newStep.toString();
      }
      
      console.log(`🔄 更新URL步骤参数: ${currentStepInUrl} -> ${newStep}`);
      router.replace({
        query: currentQuery
      }).catch(() => {});
    }
  }
}, { immediate: true });
```

### 方案3：防抖处理，避免频繁更新

```
import { debounce } from 'lodash-es';

// 监听步骤变化（防抖处理）
watch(activeStep, debounce((newStep, oldStep) => {
  console.log(`🔄 步骤变化: ${oldStep} -> ${newStep}`);

  // 只有在步骤确实变化时才更新URL
  if (newStep !== oldStep) {
    const currentQuery = { ...route.query };
    if (newStep === 0) {
      delete currentQuery.step;
    } else {
      currentQuery.step = newStep.toString();
    }
    
    // 防抖处理，避免频繁更新
    router.replace({
      query: currentQuery
    }).catch(() => {});
  }
}, 300), { immediate: true });
```

### 方案4：完全重构，分离步骤和路由

```
// 1. 从URL初始化步骤
const initStepFromUrl = (): void => {
  const stepFromUrl = route.query.step as string;
  if (stepFromUrl) {
    const stepNum = parseInt(stepFromUrl, 10);
    if (stepNum >= 0 && stepNum <= 3) {
      activeStep.value = stepNum;
      console.log(`📊 从URL初始化步骤: ${stepNum}`);
    }
  }
};

// 2. 监听步骤变化，更新URL（但不触发重新加载）
const syncStepToUrl = (step: number): void => {
  // 获取当前URL参数
  const currentParams = { ...route.params };
  const currentQuery = { ...route.query };
  
  // 更新step参数
  if (step === 0) {
    delete currentQuery.step;
  } else {
    currentQuery.step = step.toString();
  }
  
  // 只有在参数确实变化时才更新URL
  const currentStepInUrl = parseInt(route.query.step as string) || 0;
  if (currentStepInUrl !== step) {
    console.log(`🔄 同步步骤到URL: ${currentStepInUrl} -> ${step}`);
    router.replace({
      params: currentParams,
      query: currentQuery
    }).catch(() => {});
  }
};

// 3. 在onMounted中初始化
onMounted(() => {
  console.log("🔄 商品详情页面开始加载");
  initStepFromUrl();
  
  // 确保DOM更新完成
  await nextTick();
  console.log("✅ 商品详情页面加载完成");
});

// 4. 监听步骤变化
watch(activeStep, (newStep, oldStep) => {
  console.log(`🔄 步骤变化: ${oldStep} -> ${newStep}`);
  
  // 同步到URL
  syncStepToUrl(newStep);
  
  // 其他步骤切换逻辑...
}, { immediate: true });
```

## 🎯 推荐方案

**方案1（最简单）**：如果你不需要在URL中保存步骤状态，直接移除 `router.replace()`调用。

**方案2（最稳定）**：如果你需要在URL中保存步骤状态，使用条件判断避免循环触发。
