## ✅ 根本原因

**问题出在**：路由监听器中的代码在特定条件下**清空了商品信息**，导致页面重新渲染时数据丢失。

具体是这行代码：


## 🎯 总结

**根本原因**：路由监听器在特定条件下触发了"新增模式重置"，导致数据被清空。

**解决方案**：

2. 添加多重数据备份机制
3. 在组件间添加数据恢复逻辑
